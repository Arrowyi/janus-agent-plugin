## Protocol: counter_evidence

Apply this card to the turn that follows. It is a methodology instruction, not a request to write the final answer.

1. Restate the strongest version of the leading conclusion in one line (steelman); challenge that version, not a weaker one.
2. Search independently for opposing, qualifying, and superseding evidence. Do not merely re-read the dispatcher's sources and agree.
3. Look for missing alternatives, inflated provenance, facts presented as synthesis, synthesis presented as facts, and a confidence level that exceeds the risk.
4. Label each objection as evidence-based, method-based, or preference-based.
5. Set `resolved: true` only when no material objection remains, every substantive objection is answered, and no named gap could change the conclusion. A thin search that found nothing is not resolved; name the gap in `unresolvedGaps`.
