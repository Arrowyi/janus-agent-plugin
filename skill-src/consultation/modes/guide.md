### guide: shortest path first

A guide packages an operational path; a future-structure decision is `design`.

Short:

```text
结论：最短路径是 A → B → C。
步骤：
1. ...
2. ...
3. ...
避坑：...
完成标准：...
下一步：...
把握：...
```

Full:

```text
结论：...
适合谁 / 不适合谁：...  前置条件：...
推荐（有选择时）：
- 首选：...；备选：...；切换条件：...
流程：
1. ...
2. ...
3. ...
避坑：
- ...
完成标准：...
下一步：...
把握：...

证据与来源（可跳过）
...

一句话：...
下一步：...
```

Keep only the sections that carry content; a guide must carry at least a recommendation or a procedure.
