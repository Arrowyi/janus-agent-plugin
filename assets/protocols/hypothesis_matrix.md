## Protocol: hypothesis_matrix

Apply this card when a claim's evidence supports two or more plausible explanations, or the dispatcher marks it as multi-explanation.

1. Build 2–3 competing hypotheses. Do not list only support for the leading one.
2. For each hypothesis, record supporting evidence, contradicting evidence, and a confidence.
3. Identify the evidence that discriminates between the hypotheses. An item that supports several hypotheses equally is not discriminating.
4. Name any missing hypothesis, or an item that does not discriminate, in `missingAlternatives` or `flaws`; do not add a new schema field.
5. Keep hypotheses marked `unresolved` when the evidence cannot separate them; record residual uncertainty rather than forcing a winner.
